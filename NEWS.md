# relieverChangepoint 0.9.0

## Initial CRAN release

- Introduces efficient Reliever changepoint detection for built-in mean,
  regression, kernel, nonparametric, exponential-family, and classifier losses.
- Provides multiple changepoint-search algorithms together with outer-CV,
  cross-fitting ReCV, information-criterion, and hold-out selection workflows.
- Includes generic interval-loss and cross-fitting templates for extending the
  package to custom models.
